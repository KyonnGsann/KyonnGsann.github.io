プライバシーポリシー

TesLock（以下、本アプリ）の個人情報の扱いについて説明します。

集めないもの

本アプリはアカウント登録を求めません。氏名、メールアドレス、電話番号、位置情報は取得しません。 作成した問題文と答えは端末の中だけに保存され、開発者が見ることはできません。

端末の外に出るもの

「教科書を撮る」で撮影した写真は、問題の候補を作るために中継サーバーを通じて Anthropic の Claude API に送られます。送った写真は候補の生成にだけ使われ、保存されません。 写真を送ることは、撮影を選ぶ前の画面で毎回お知らせします。

SNS への投稿について

開発者は TesLock の紹介動画を X・YouTube・Instagram・TikTok に投稿しています。 投稿に使うのは開発者が作った動画だけで、利用者のデータは一切含まれません。 これらの連携は開発者自身のアカウントに対してのみ行われます。

記録の書き出し

設定から学習の記録を書き出せます。書き出されるのは回数と時刻と番号だけで、 問題文や問題集の名前は含まれません。

子どもの利用

本アプリは学生の利用を想定しています。上記のとおり個人を特定する情報を集めません。
